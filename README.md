# Profile Card Application

A responsive profile card application built with React.js and Tailwind CSS.

## Features

- View Profile
- Edit Profile
- Responsive Design (Mobile & Desktop)
- Contact Information
- Social Links
- Skills Section

## Tech Stack

- React.js
- Tailwind CSS
- JavaScript

## Run Project

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm start
```
